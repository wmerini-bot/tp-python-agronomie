# 🌱 Agricultural Data Analysis

## Project Description
This project aims to help agronomists analyze agricultural data using Python. It provides basic statistical analysis of crop production, cultivated areas, and rainfall.

## Objectives
- Read and explore agricultural datasets.
- Calculate total and average crop production.
- Calculate agricultural yield (tons per hectare).
- Identify the crop with the highest productivity.
- Support agricultural decision-making through data analysis.

## Dataset Description

The dataset contains the following variables:

| Variable | Description |
|---|---|
| Crop | Name of the crop |
| Area_ha | Cultivated area in hectares |
| Production_t | Production in tons |
| Rainfall_mm | Rainfall in millimeters |

## Technologies Used
- Python
- Pandas

## Installation

Install the required library:

```bash
pip install pandas
```

## How to Run

```bash
python python-file.py
```

## Expected Results
The program displays:
- Total agricultural production.
- Average production.
- Productivity for each crop.
- Crop with the highest productivity.
